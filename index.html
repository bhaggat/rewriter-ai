Frequently Asked Questions

Everything You Need to Know

How does Bring Your Own Key (BYOK) work? ▼
You generate an API key directly from OpenAI, Google AI Studio, Anthropic, xAI, Groq, Mistral, or OpenRouter and paste it into the extension settings. The extension uses that key to make API calls straight to the provider at raw developer rates.
Is Rewriter AI completely free to use? ▼
Yes! Rewriter AI is 100% free and open-source under the MIT license. You only pay your chosen AI provider directly for the API tokens you consume (which is typically fractions of a cent per request).
Can I change the keyboard shortcut? ▼
Yes. The default shortcut is Alt+Shift+R (or Option+Shift+R on Mac). You can easily customize it to any key combination by visiting chrome://extensions/shortcuts in your browser.
Does the extension read all the web pages I visit? ▼
No. The content script strictly activates only when you focus an editable text input or textarea. It only reads the specific text content inside that active field when you trigger a rewrite—never the surrounding webpage content.
